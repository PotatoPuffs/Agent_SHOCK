🕹️ Game Environment (aiming.pro)
▼

The target game is aiming.pro — a browser-based aim training platform with lateral-movement drills. Targets move left and right randomly, and the player must click on them as quickly as possible.

Input to system

  • Raw screen pixels
  • Target position (visual)
  • Cursor position (visual)

Receives from system

  • Mouse movement (left/right)
  • Mouse click events
↓ raw screen pixels
👁️ Perception "The Eyes"
▼

CNN watches the game screen in real time, detects the crosshair and target, and computes the pixel error between them — passing it to the RL agent every ~33ms.

Components

  • Screen capture (30 FPS target)
  • HSV colour masking for auto-labelling
  • CNN trained on 3000–5000 labelled frames (MSE loss, Adam optimiser)

Output

  • [Cx, Cy, Tx, Ty] → computes Δx, Δy error (x, y) pixel error
OpenCV CNN mss NumPy

🧠 Cognition "The Brain"
▼

The RL agent maps pixel error to a stimulation command. Trained in simulation via PPO with a sim-to-real curriculum, the agent learns to minimise error and hit targets as accurately as possible.

Observation space

  • norm_error (float)
  • norm_cursor_x (float)
  • last_dx_norm (float)
  • pulse_dur_norm (float)

Action space

  • left
  • right
  • click

Reward

  • −|error|/width per step
  • +10 on hit
  • −2 on miss
  • −5 on timeout

Training

  • Algorithm: PPO
  • Steps: 250k–500k
  • Library: Stable-Baselines3
  • Env: custom Gym
Stable-Baselines3 PPO OpenAI Gym TensorBoard
Owner: Dyandra Prins · Angelyn Co

⚡ Middleware "The Nervous System"
▼

Bridges the Python software layer and the Arduino hardware. Translates agent commands into single-character serial messages and transmits to the MCU over USB at 9600 baud.

Serial protocol

  • L → left relay ON
  • R → right relay ON
  • C → click relay ON
  • N → all relays OFF

Python middleware

  • serial_test.py
  • Spacebar toggle loop
  • L → R → C sequence
  • Baud rate: 9600
PySerial pynput Python PlatformIO
Owner: Osmond Lau

↓ serial pixel data → relay trigger
💪 Actuation "The Muscles"
▼

The hardware layer. An Arduino MCU triggers relay modules connected to a TENS unit, which delivers electrical pulses to forearm and hand electrodes — causing muscle contractions that physically move the mouse.

Hardware

  • Arduino Uno
  • 3× relay modules
  • TENS/EMS unit
  • 6× electrode pads

Safety limits

  • Max pulse: 800ms
  • Cooldown: ≥500ms
  • Forearm and hand
Arduino C++ TENS unit Relay circuit EMS electrodes
Owner: Jake Nockles

↓ forearm contraction → cursor moves
🖱️ Output (cursor left/right + click)
▼

The end result: the human forearm physically moves the mouse cursor left or right, and triggers a click when the agent decides to fire. The game registers the input as a normal mouse event — it has no idea a robot is involved.

The loop then repeats: the game updates → Perception reads the new state → Cognition decides → and so on.

↑ game state updates → loop repeats
