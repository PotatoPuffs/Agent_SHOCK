📋 Project Overview
_
□
✕

Agent_SHOCK is a closed-loop computer interface. A reinforcement learning agent trained in simulation learns to aim at moving targets in a browser game, then its outputs are delivered as electrical pulses to a human forearm via a TENS device, physically moving the mouse.
